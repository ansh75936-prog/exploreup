# Project agent skills

The UI/UX Pro Max skill is pinned as a Git submodule at `vendor/ui-ux-pro-max-skill` and linked into `.agents/skills/ui-ux-pro-max`.

After cloning this repository, run:

```bash
git submodule update --init --recursive
```

Then use the `ui-ux-pro-max` skill for UI design, accessibility, responsive layout, typography, and design-system work. Its local data and scripts are exposed through symlinks in the skill directory.
